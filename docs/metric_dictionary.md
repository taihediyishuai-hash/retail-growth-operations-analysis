# 指标口径表

| 指标 | 定义 | 分子 | 分母/实体 | 排除与限制 |
|---|---|---|---|---|
| 毛销售额 | 正数量商品行的 `Quantity × Price` 之和 | 正向商品金额 | 交易行 | 不含非商品代码、零价和完全重复行 |
| 退货/取消金额 | 负数量商品行金额绝对值之和 | 负向商品金额绝对值 | 交易行 | 按冲回发票发生日统计，未回溯原销售日 |
| 净收入 | 毛销售额－退货/取消金额 | 毛销售额－冲回 | 交易行/月 | 不是会计确认收入，缺少税费、折扣和成本 |
| 正向订单数 | 毛销售额大于 0 的去重发票数 | 去重 `Invoice` | 发票 | 发票是订单主键；时间取发票内最早时间 |
| 毛客单价 | 毛销售额／正向订单数 | 毛销售额 | 正向订单 | 与净收入分开，避免跨期冲回污染分母 |
| 90 天复购率 | 首笔可观测购买后 90 天内出现第二张更晚正向发票的客户数／双向成熟客户数 | 90 天内二购客户 | 该笔购买前拥有 90 天历史洗脱且其后拥有完整 90 天观察窗的客户 | 缺客户编号、左截断和右删失客户不进入分母；不等同于生命周期绝对首购 |
| 月度回访客户占比 | 首笔可观测购买月早于当前月且当前月购买的客户／当前月购买客户 | 回访客户 | 当月有正向订单且有客户编号的客户 | 不是 90 天复购率，也不是产品活跃留存 |
| RFM Recency | 2011-12-10 距最后一次正向购买的天数 | 日数 | 有客户编号的购买客户 | 越小越好，参考日固定 |
| RFM Frequency | 历史正向发票去重数 | 订单数 | 有客户编号的购买客户 | 单次购买客户单列 One-time |
| RFM Monetary | 历史正向购买金额扣除退货/取消后的客户净收入，负值按 0 进入评分 | 客户净收入 | 有客户编号且至少有一张正向购买订单的客户 | 23 名只有退货记录的客户被排除，其净额为 -1,406.13；评分前对 1%/99% 极端值 winsorize，同时保留毛购买额与原始净收入供审计 |

项目没有访问、曝光、加购、成本、毛利、营销触达和随机对照，因此不计算漏斗转化率、CAC、ROI 或营销增量。
