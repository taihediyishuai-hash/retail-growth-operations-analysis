# 零售用户增长与复购运营分析

面向数据运营岗位的个人作品集项目。基于 UCI Online Retail II 的 **1,067,371 行真实公开交易明细**，完成数据质量治理、SQLite 指标层、月度经营分析、首笔可观测购买同期群、90 天复购、标准 RFM 分层、运营动作设计和离线 HTML 报告。

> 项目身份：个人项目；数据来自公开数据集，不是任职公司或客户数据。运营方案尚未真实投放，项目不声称带来收入或复购提升。

## 项目解决什么问题

运营资源有限时，需要同时回答两个问题：

1. 哪些客户群应优先进入召回、二购培育或忠诚维护？
2. 触达后用什么分母、观察窗和对照方式判断策略是否有效？

项目以**净收入**和**首笔可观测购买后 90 天复购率**为主指标。月度趋势用于判断经营背景，双向成熟 cohort 用于比较复购，RFM 用于描述历史价值和当前活跃状态。

## 已完成的可核验结果

- 原始 1,067,371 行，按明确规则清洗后保留 1,021,335 行；删除 34,037 条时间戳完全相同的重复记录。
- 清洗后净收入 18,928,585.46，毛销售额 19,645,080.99，退货/取消金额率 3.65%；7 个可加总指标全部通过表内对账。
- 同时满足首笔可观测购买前 90 天历史洗脱和其后 90 天完整观察窗的 3,562 名客户中，1,476 人在 90 天内产生第二张正向商品发票，复购率 41.44%。
- 以 2011-12-10 为固定参考日完成 5,852 名购买客户的 RFM：Champions 占 21.84% 客户、对应 69.11% 客户净收入；At risk 为 619 人，平均距上次购买 359.19 天。
- 单次购买客户 1,618 人，占 27.65%，单列为 One-time，避免把一次交易强行解释成稳定 RFM 行为；Monetary 使用客户净收入，避免高退货客户被误判为高价值。

以上都是历史数据描述。RFM 不预测营销响应，客户编号缺失的订单不进入复购和 RFM。

## 运营动作与验证方式

| 优先级 | 人群 | 用途 | 验证方式 |
|---|---|---|---|
| 1 | At risk | 高历史价值沉默召回 | 随机保留对照组，比较 30 天回购率与净收入/触达客户 |
| 2 | One-time | 首笔可观测购买后第二单培育 | 该笔购买后 7/14 天随机分组并保留不触达对照，比较成熟 cohort 的 90 天复购率 |
| 3 | Champions | 忠诚维护与流失预警 | 监控 30 天未购占比、复购间隔和退货金额率 |
| 4 | Loyal | 稳定复购维护 | 保留随机对照，比较购买间隔和净收入护栏 |

动作是实验方案，不是已经发生的业务结果。缺少营销成本和毛利时，不计算 ROI。

## 数据口径与限制

- 数据来源：[UCI Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii)，许可为 CC BY 4.0；原始文件 SHA-256 已固定。
- `Quantity < 0` 按退货或取消冲回处理；净收入不等同于会计确认收入。
- 客户编号在清洗后交易行中缺失 22.24%；有客户编号的发票覆盖 86.42% 净收入。用户指标只代表可识别客户子集。
- RFM 只覆盖有正向购买订单的 5,852 名客户；另有 23 名客户只有退货记录，合计净额 -1,406.13，因此不具备可定义的最近购买日与购买频次。
- 2011-12 只有 9 天，排除出完整月份比较；末端首笔可观测购买 cohort 未满 90 天时不进入 90 天复购率。
- 数据没有曝光、访问、加购、营销触达、随机对照、商品成本和毛利，不能计算完整漏斗、CAC、ROI 或营销增量。
- 数据来自一家英国零售商，不能直接外推到其他行业或企业。

完整定义见 [指标口径表](docs/metric_dictionary.md)。

## 技术实现

- **Python / pandas**：原始明细清洗、订单重建、复购窗口、同期群和 RFM。
- **SQLite / SQL**：订单与指标表落库，5 组可独立执行的业务查询。
- **Matplotlib / Seaborn**：月度趋势、同期群、RFM 价值结构和运营优先级图。
- **Streamlit**：经营趋势、复购同期群、RFM 动作和质量门禁四个页面。
- **质量与证据校验**：数据画像、质量门禁、表内对账、数字溯源和 HTML 报告。

## 快速复现

```bash
python3 -m pip install -r requirements.txt
python3 src/download_data.py
python3 src/build_project.py
python3 src/run_sql_analysis.py
python3 src/build_evidence.py
python3 src/create_figures.py
python3 tests/test_project.py
streamlit run app.py
```

看板默认地址：`http://localhost:8501`。

原始数据约 95 MB，不进入版本控制；下载脚本会校验 SHA-256。核心分析不依赖 Codex，安装依赖后可独立复现。HTML 报告及证据门禁在 `outputs/run_20260915/`。
