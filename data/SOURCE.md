# 数据来源

- 数据集：Online Retail II
- 发布方：UCI Machine Learning Repository
- 官方页面：https://archive.ics.uci.edu/dataset/502/online+retail+ii
- 许可：CC BY 4.0
- 覆盖时间：2009-12-01 至 2011-12-09
- 原始规模：1,067,371 行交易明细
- 下载镜像：https://huggingface.co/datasets/attik/Online-Retail-II-UCI/resolve/main/online_retail_II.csv
- 记录的 SHA-256：`32569a66f3842a82b0d8c4d63b263c5d98a76bde5d1f65c6c01bf457e541d3a9`

原始文件约 90 MB，不纳入版本控制。运行 `python src/download_data.py` 可以重新下载并校验。

这是公开匿名交易数据，不是本人任职公司或客户的内部数据。项目中的运营动作是基于历史数据提出的待验证方案，没有真实投放结果。
